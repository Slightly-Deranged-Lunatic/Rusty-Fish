## Does this install files anywhere?

Yes, it pulls files from the repository and writes them to the following directories

Linux: `~/.local/share/rusty-fish`

Windows: `C:\Users\{user}\AppData\Roaming\deranged-lunatic-apps\rusty-fish\data`

MacOS: `/Users/{user}/Library/Application Support/deranged-lunatic-apps.rusty-fish`
Note: Not entirely sure about this one because I can't test it
